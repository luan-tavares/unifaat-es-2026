Fluxo Git do aluno

O aluno só precisa do main (cópia do professor, só pull) e de uma branch por TF, RA-tf-NN, que vira Pull Request e nunca é mergeada. A preparação acontece uma vez; depois é um ciclo de 4 etapas que se repete a cada aula.

ANTES DE CLONAR: faça o FORK do repositório do professor (botão Fork no GitHub) e clone o seu fork. Clonar o repo do professor direto não funciona: o push é recusado.

REGRA DA ENTREGA: criar UMA BRANCH POR TF, com a nomenclatura certa: RA-tf-NN (ex.: 6325000-tf-12), com, na raiz, o diretório RA/tf-NN/ contendo o RA.txt (nome, RA e GitHub). O TF só vale se o PR aparecer no repositório do professor.

Clique em próximo (ou use as setas ← → do teclado) para a timeline evoluir um passo por vez.
