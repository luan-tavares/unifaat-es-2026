  • Inteiro (Aula 03): número na base 2. String (Aulas 03 e 07): cada caractere é um número da tabela, e o número vira binário
  • O 65 e o "A" são os mesmos bits: o tipo é a lente que lê

O computador não tem "número", "texto" nem "lista": só sequências de bits. A estrutura de dados é como esses valores se organizam.

Em Python tudo é objeto: não há primitivo "puro" como o int do Java. Os que se comportam como primitivo são os imutáveis. Os de referência são as estruturas de dados.

is pergunta "é o mesmo objeto?"; == pergunta "têm o mesmo valor?". É o mesmo mecanismo do self e do pai da árvore de arquivos.

Leitura x escrita: ganhar de um lado é perder do outro

Leitura consulta sem mudar; escrita inclui, altera ou remove. As duas são antagônicas: organizar para ler rápido (ordem, índice, hash) dá trabalho na escrita; facilitar a escrita obriga a varrer na leitura.

Lista: o array do Python (vetor = array)

Ganha: ler por posição. Perde: escrever no início ou no meio.

Tupla: imutável

Ganha: segurança, e vira chave de dicionário. Perde: a escrita: "alterar" é copiar tudo.

Dicionário: o famoso HashMap

Ganha: ler e escrever pela chave em 1 passo. Perde: memória extra e a busca pelo valor.

Um só professor na memória, duas turmas guardando o endereço dele. Uma lista de objetos já é uma estrutura de dados.

Pilha: o último a entrar é o primeiro a sair

Ganha: simplicidade, o topo em 1 passo. Perde: o acesso ao meio e ao fundo.

Fila: o primeiro a entrar é o primeiro a sair

Ganha: a ordem de chegada, frente e fim em 1 passo. Perde: o meio (e o pop(0) da lista comum).

Árvore: hierarquia, um pai por nó

Ganha: hierarquia e escrita local barata (mover um galho é 1 ponteiro). Perde: a busca global, sem o caminho.

Grafo: nós e ligações, sem hierarquia

Ganha: modela qualquer relação e lista vizinhos direto. Perde: "A liga a B?" e remover varrem a lista. Caso real: o Git. Commit é nó, "pai" é aresta, merge é nó com dois pais. A árvore é um grafo sem ciclos.

Não existe estrutura que ganhe em tudo. A pergunta é sempre: vou mais ler ou mais escrever, e o quê?
