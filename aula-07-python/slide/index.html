Chave SSH: um par por máquina

Cada ambiente gera o seu próprio par de chaves. O WSL guarda o dele em ~/.ssh/ e o Windows em C:\Users\NOME\.ssh\: no mesmo notebook, são dois pares diferentes, um pro Linux do WSL e outro pro Windows — ambientes isolados, como na Aula 02.

Python é um binário que lê texto

Como ls e git, python3 é um binário (escrito em C). Ele lê um arquivo .py, que é texto puro, e executa: por isso o Python é uma linguagem interpretada.

~
# onde está o binário que o terminal vai executar?
$ which python3
/usr/bin/python3
# o binário lê o arquivo de texto e executa
$ python3 ola.py
Olá, mundo!

Por que python3 e não python? Em 2008 o Python 3 quebrou a compatibilidade com o 2, e as duas versões conviveram até 2020 — cada uma com o seu binário.

Decimal → binário

binario.py
def decimal_para_binario(numero):
# caso de borda: no quadro ninguém converte o zero
if numero == 0:
return "0"
binario = ""
while numero > 0:
resto = numero % 2
# resto novo vai NA FRENTE: é o "ler de baixo pra cima"
binario = str(resto) + binario
numero = numero // 2
return binario
print(decimal_para_binario(45)) # 101101
print(decimal_para_binario(65)) # 1000001 -> o "A"

Trocar pra binario + str(resto) inverte o resultado — o mesmo erro do quadro, agora em código.

Testando os 256 valores de um byte

Testar alguns números à mão é um começo. Um engenheiro compara com uma referência confiável — em muitos casos de uma vez. O bin() do Python é a referência; o assert para tudo se a comparação falhar.

binario.py
print(bin(45)) # 0b101101 (o "0b" é só o prefixo)
print(int("101101", 2)) # 45 -> o caminho de volta
for n in range(256):
assert decimal_para_binario(n) == bin(n)[2:]
print("Os 256 valores de um byte conferem!")

Três linhas conferem o byte inteiro. É o embrião dos testes automatizados.

Bubble sort: compara vizinhos e troca

ordenacao.py
def bubble_sort(valores):
lista = valores.copy() # não mexe na lista de quem chamou
n = len(lista)
for passada in range(n - 1):
trocou = False
for i in range(n - 1 - passada):
if lista[i] <= lista[i + 1]:
continue # já em ordem: sem else
lista[i], lista[i + 1] = lista[i + 1], lista[i] # troca via tupla
trocou = True
if not trocou:
break # passada sem troca: pronto
return lista

Passada a passada

passadalista no fim da passadao que aconteceu
início[7, 3, 9, 1, 5]—
1[3, 7, 1, 5, 9]o 9 chegou ao fim
2[3, 1, 5, 7, 9]o 7 chegou ao lugar
3[1, 3, 5, 7, 9]3 e 1 trocaram
4[1, 3, 5, 7, 9]nenhuma troca: para

Merge sort: dividir por 2 até não dar mais

  • Dividir: corta a lista ao meio, e cada metade ao meio de novo, até sobrar 1 item (1 item já está ordenado)
  • Conquistar: junta (intercala) as metades de volta, sempre em ordem
# dividir
[7, 3, 9, 1, 5, 8, 2, 6]
[7, 3, 9, 1]   [5, 8, 2, 6]
[7, 3] [9, 1]   [5, 8] [2, 6]
[7] [3] [9] [1]   [5] [8] [2] [6]
# conquistar
[3, 7] [1, 9]   [5, 8] [2, 6]
[1, 3, 7, 9]   [2, 5, 6, 8]
[1, 2, 3, 5, 6, 7, 8, 9]

8 itens → 3 divisões por 2 (2³ = 8). A mesma divisão por 2 do binário, agora aplicada a uma lista.

Merge sort em Python

ordenacao.py
def merge_sort(lista):
if len(lista) <= 1: # caso base: 1 item já está ordenado
return lista
meio = len(lista) // 2 # dividir por 2
esquerda = merge_sort(lista[:meio]) # a função chama a si mesma
direita = merge_sort(lista[meio:])
return intercalar(esquerda, direita)
def intercalar(esquerda, direita):
resultado = []
i = 0
j = 0
while i < len(esquerda) and j < len(direita):
if esquerda[i] <= direita[j]:
resultado.append(esquerda[i])
i += 1
continue # sem else
resultado.append(direita[j])
j += 1
resultado.extend(esquerda[i:]) # o que sobrou de um dos lados
resultado.extend(direita[j:])
return resultado

Uma função que chama a si mesma em partes menores é recursiva — o mesmo conceito do rm -r da Aula 03.

Por que dividir por 2 importa

Quantas vezes dá pra dividir 1.000 por 2 até chegar em 1? Umas 10 — a mesma quantidade de dígitos de 1.000 em binário (1111101000). O merge sort faz ~10 rodadas de intercalação; o bubble sort compara quase todo mundo com todo mundo.

itensbubble sort (pior caso)merge sort
1.000~500 mil comparações~10 mil
1.000.000~500 bilhões~20 milhões

O sorted() do Python usa o Timsort, que é construído em cima do merge sort. Dividir por 2 vai voltar muito nas próximas aulas.
